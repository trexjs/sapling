# Xlox UI Demo - Color & Typography Showcase

A React web application showcasing the complete Xlox UI color system and typography components.

## 🎨 Features

### **Color Showcase**
- **23 color families** with 11 shades each
- **Interactive color cards** - Click to explore each family
- **Copy to clipboard** - Click any color swatch to copy hex code
- **253 total colors** available

### **Typography Showcase**
- **13 typography variants** (h1-h6, subtitle1-2, body1-2, caption, overline, button)
- **Text colors** - Primary, secondary, brand colors
- **Text alignment** - Left, center, right, justify
- **Text wrapping** - Normal wrap and no-wrap examples

## 🚀 Getting Started

### Install Dependencies
```bash
cd demo
npm install
```

### Run Development Server
```bash
npm run dev
```

The app will open at `http://localhost:3000`

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```

## 🎯 Tabs

### 1. **Colors Tab**
- Grid view of all 23 color families
- Click any color to see all 11 shades
- Each shade displays hex code
- Click to copy hex value

### 2. **Typography Tab**
- All typography variants with examples
- Headings (h1-h6)
- Subtitles (subtitle1-2)
- Body text (body1-2)
- Small text (caption, overline, button)
- Text colors demonstration
- Text alignment examples
- Text wrapping examples

### 3. **All Colors Tab**
- Complete palette view
- All 23 families displayed at once
- Interactive color swatches
- Copy hex codes on click
