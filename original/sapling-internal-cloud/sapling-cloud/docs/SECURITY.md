# Security posture
**Prototype only. Not production safe.** Shared admin token, caller-controlled tenant headers, no authorization engine, no CSRF hardening, no per-tenant isolation enforcement, no API throttling, no TLS termination, no secrets encryption, and no audit tamper protection. Do not expose publicly or use real secrets. Before production: identity-backed JWT/OIDC with server-derived tenant membership, RBAC/ABAC, DB RLS or isolated tenant databases, mTLS, KMS, token rotation, request limits, strict CORS, security scanning, transactional audit/outbox, and penetration testing.
