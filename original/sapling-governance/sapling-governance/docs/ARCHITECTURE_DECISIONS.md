# Architecture Decisions

ADR-001: Single monorepo, independently deployable ConsentOS and ComplianceOS APIs.
ADR-002: PostgreSQL with Drizzle ORM and domain-owned schemas.
ADR-003: One React console with 18 routes; eventually replace generic forms with dedicated workflow screens.
ADR-004: Existing Sapling services are external integrations; do not duplicate their identity/audit/document capabilities.
ADR-005: Fail closed for production startup until authentication is integrated.
ADR-006: No claim of compliance certification without independent verification.
